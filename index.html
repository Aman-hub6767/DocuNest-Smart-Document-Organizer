Backup and Restore

Important: Your documents are stored only in this browser. If you clear the browser's site data, they are deleted permanently. Keep your original files on your computer.

What does the backup contain?

Included: names, categories, tags, notes, favorites, file sizes and dates.
Not included: the actual files (PDF, images, text).

Restore applies the saved details to documents that are already in DocuNest. A backup entry matches a document when the original file name and the file size are the same. You will be asked to confirm before anything changes. Restore does not bring back deleted files.
